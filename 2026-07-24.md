### [What keyboard shortcuts are we planning for in CodePen v2 — CodePen Radio 430 ](https://www.youtube.com/watch?v=m1ZcdFpdBHY)

- Operating system has reserved keyboard shortcuts, browsers also have reserved shortcuts that you can't override (for example Cmd + T = new tab cannot be used in browsers but Cmd + S = save is not important to browsers so you can override it)
- You have to consider supporting different operating systems (Ctrl on Windows vs Cmd on Mac)
- Some users are super users or have custom keyboards and might want to customise shortcuts

### [L8 Principal's Agentic Engineering Workflow](https://www.youtube.com/watch?v=iQyg-KypKAA&t=16s)

Coding agents

Claude
Codex, pi, opencode (more customisable agents)

- Onboarding the agents: memory files and skills
- Memory files can be global and project
- Memory files should be concise to avoid using a lot of tokens
- Can be used for general preferences (for example, do not factor in development cost when making technical decisions because estimates are going to be based on how long it takes humans to develop the features or prefer e2e tests to unit tests)
- You can add information to the memory file based on mistakes the agent often makes
- You can keep context minimal for general requests by moving specific instructions to separate skills
- 10 principles for making tools highly efficient for agents: [axi.md](https://axi.md/)
- when working with agents, you should act like a team manager creating a good culture and process that ensures efficient work rather than reviewing code (which is too much overhead)
- you can automate the creation of MRs and the MR review (for example using no-mistakes)
- the most time should be spent on planning and validating the task, everything else should be handled by agents
- using git worktrees to separate agents working on the same codebase (using treehouse)
