### [How LLMs Actually Generate Text (Every Dev Should Know This)](https://www.youtube.com/watch?v=NKnZYvZA7w4)

Text generation pipeline:

- Tokenisation: text becomes pieces
- Embeddings: pieces become meaningful vectors (coordinates in a meaning space)
- Transformer: context gets processed through attention
- Probabilities: every possible next token is scored
- Sampling: one token is selected (based on probability and "temperature")

### [Most devs don’t understand how context windows work ](https://www.youtube.com/watch?v=-uW5-TaVXu4)

- the context window is the main agent constraint
- input + output = context
- the context window grows as the conversation continues
- the large a context window is, the more the context degrades
- the attention mechanism of the agent evaluates the middle of the conversation as least important
- compacting and clearing are ways of freeing up context
- MCP servers and agent rules can bloat the context
