### [OPERATING SYSTEMS (how computers actually work)](https://www.youtube.com/watch?v=V-Oz_rxidtU)

- Operating systems are the interface that abstracts all of the hardware
- abstractions provided by operating systems: layers of execution, kernel mode, user mode and sys calls, file systems

User vs Kernel mode in OSs

- all computers have CPU (sometimes with multiple cores) and their job is to execute sequences of instructions
- abstractions used when writing software: functions, classes, routines, forking processes, forking into threads, subroutines
- operating system kernel = core piece of code, direct interface between the CPU and everything else

kernel mode | user mode
hadware < kernel < system calls < system libs < user space

- the user mode has its own stack of execution

System calls

- abstracted to look like functions that you can call from an application that is running or from within the system libraries

examples: read(2), write(2), open(2), close(2), fork(2), exec(2), mmap(2), stat(2)

What is a process?

- Process = abstaction over the CPU that can run instructions
- Program = compiled version of the source code saved on disk, process = instance of the program created on a system that's loaded in memory and given virtual memory
